Why run a billing counter on Linux?

  • No operating-system licence. On a second or third counter PC, that saves real money.
  • Older hardware lives longer. A five-year-old office PC that struggles with the latest Windows often runs a lightweight Linux desktop comfortably.
  • Updates on your schedule. Linux does not restart itself in the middle of service to install updates.
  • Fewer distractions. A counter PC that only runs the POS and a browser is harder to misuse.

The catch is that your software has to support it. Many restaurant POS products are Windows-only or browser-only; check before you wipe a machine.

Choose the distribution

If you have no preference, use Ubuntu LTS or Linux Mint. Both are Debian-family, so .deb packages install directly, both have long support periods, and Mint's desktop feels familiar to staff who have only used Windows. Use the 64-bit version; most POS builds are x86_64 only.

Which file: .deb or AppImage?

Find out what you are running:

cat /etc/os-release | head -2

If it says Ubuntu, Debian, Linux Mint, Pop!_OS or elementary, use the .deb. It installs properly, appears in the applications menu, and can be removed with one command. On Fedora, Arch, openSUSE or anything else, use the AppImage: one portable file, nothing installed.

Installing a .deb (example: Pass)

wget https://github.com/The-Binary-Brain-Network/pass-releases/releases/latest/download/Pass-amd64.deb
sudo apt install ./Pass-amd64.deb

Start it from the applications menu, or from a terminal:

pass-pos

To remove it later:

sudo apt remove pass-pos

Running an AppImage

wget https://github.com/The-Binary-Brain-Network/pass-releases/releases/latest/download/Pass-x86_64.AppImage
chmod +x Pass-x86_64.AppImage
./Pass-x86_64.AppImage

Linux will not run a downloaded file until you mark it executable — that is what chmod +x does.

The libfuse error

On Ubuntu 22.04 and newer, an AppImage may refuse to start with a message about libfuse.so.2. Those releases stopped shipping FUSE 2, which AppImages rely on. Either install it once:

sudo apt install libfuse2

or run without FUSE:

./Pass-x86_64.AppImage --appimage-extract-and-run

On a Debian-family system, simply switching to the .deb avoids the issue.

Thermal printers on Linux

Printers are the one area where Linux and Windows genuinely differ. Most 80mm USB and network thermal printers sold in India are generic ESC/POS devices.

  1. Connect the printer and open the system's printer settings. Network printers can be added by IP address.
  2. If the manufacturer offers a Linux (CUPS) driver, install it. Otherwise, a generic or raw queue often works for ESC/POS printers.
  3. Name the queue clearly — BILL, KOT-KITCHEN — so you choose the right one in the POS.
  4. Print a test page from the POS, not just from the system, and check width and cut.

For network printers, give each one a fixed IP address in your router so it does not move after a power cut. Our thermal printer troubleshooting guide covers blank prints, wrong widths and missing cuts.

Small things that help

  • Turn off screen lock during service hours, or set a long timeout.
  • Add the POS to startup applications so it opens when the PC boots.
  • Use a UPS — a power blip should never reboot the counter mid-bill.
  • Keep the PC on a wired connection if it also drives network printers.

About Pass on Linux

Pass ships the same version for Linux as for Windows, built from the same source in the same release, with the same features: billing, KOT routing, the kitchen display, multiple outlets, inventory, staff and reports. Linux builds are x86_64 only, as a .deb and an AppImage, and update themselves. Full copy-paste commands are on the Pass Linux section; Slate and Folio also run on Linux.
