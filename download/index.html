Installing on Windows.

  1. Download the Windows installer for your product above.
  2. Open it. If Windows shows "Windows protected your PC", click More info and then Run anyway — this appears because the installer is not code-signed yet.

Questions

Before you download.

Is the trial really free?
Yes. Every TBN product runs as the complete software for 15 days with no card taken and no feature switched off. If you do nothing at the end of the trial, nothing is charged — the software simply asks for a licence key.
What happens when the 15 days end?
The app stops at its licence screen until a paid key is entered. Your data stays on your computer; nothing is deleted. Enter the paid key and you carry on exactly where you left off.
Windows says "Windows protected your PC". Is it safe?
Yes. Our Windows installers are not code-signed yet, so SmartScreen shows a warning for any publisher it has not seen before. Click More info, then Run anyway. The files come straight from our official GitHub release pages, and we are arranging a signing certificate.
Which Windows versions are supported?
Windows 10 and Windows 11, 64-bit. Windows 7 and 8 are not supported.
Which Linux file should I take?
On Ubuntu, Debian, Linux Mint, Pop!_OS or elementary, take the .deb where one is offered. Anything else, take the AppImage. If an AppImage complains about libfuse.so.2, run sudo apt install libfuse2 once. Full commands are on each product page.
Can I trial on more than one computer?
Each computer gets one trial per product, and trying Folio does not use up a Pass or Slate trial. If you need a second machine for testing, message us.
Do I need internet?
Only briefly. Starting a trial and receiving updates need a connection; billing, printing, reports and backups all run fully offline after that.
Will you help me install it?
Yes. Installation, onboarding and staff training are included with every licence, and we are happy to do the trial install with you over a call.
